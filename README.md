# skillswap-ReiChikyu
Project Overview
Skill Swap is a web application that allows students to teach and learn each other. Users can browse available skills, filter by category, estimate tutoring costs, find matching skills based on their needs, and add new skills.

Features
Display skill cards dynamically from the database
Filter skills by category
Calculate session costs
Match skills based on category and budget
Add new skills
Responsive design for desktop and smaller screens such as mobile devices
