# skillswap-ReiChikyu

## Project Overview

Skill Swap is a web application that allows students to teach and learn from each other. Users can browse available skills, filter skills by category, estimate tutoring costs, find matching skills based on their needs, and add new skills through an interactive form.

## Features
- Dynamic skill card display from the database
- Category-based skill filtering
- Session cost calculator
- Skill matching based on category and budget
- Add new skills through a form
- Responsive design for desktop and mobile devices
